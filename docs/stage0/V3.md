## 2. 피험자와 세션

- 확인한 것: `participants.tsv` 행 수, `preproc_data/` 피험자 폴더 수, func run 폴더의 세션 라벨.
- 측정값:
  - `participants.tsv` 22명(sub-01–sub-22). `preproc_data/` 피험자 폴더 22개. 22명 모두 func run이 있음. ✅
  - 세션 수: 2세션 16명, 1세션 5명(sub-01, 02, 03, 09, 18), 3세션 1명(sub-17). ✅
  - `README`: "obtained from 22 individuals between the ages of 23 and 51 years-old". ✅
- sub-17: ses-01에는 checker, inscapes, rest, tp run-01만 있다. ses-03에 1일차 과제(dme, monkey1, tp run-01·02, peer 등)가 다시 있다. ✅
- 세션 간격: `scans.tsv` 40개 모두 헤더가 `filename` 하나다. sidecar 392개 전수에서 이름에 Time·Date·Acq가 든 키는 `AcquisitionNumber`, `EchoTime`, `RepetitionTime`, `TotalReadoutTime`, `AcquisitionMatrixPE`, `DwellTime`, `MRAcquisitionType`뿐이다. 날짜나 시각 필드가 없어 데이터에서는 알 수 없다. ❓
  - 논문(Telesford 외 2023, Sci Data 10:554, PMC10447527)은 "Participants attended two sessions between 2 and 354 days between scans (time between scans, mean: 38.2 days; median: 11 days)"라고 적었다. 데이터와 대조하지는 않았다. ⚠️

## 3. TR

## 5. 같은 영화의 반복 run (B·C)

- 논문 인용: "Participants viewed three movies twice in one scan session." Table 1에서 1일차는 tp, monkey1, dme의 run 1이 MPRAGE(600 s) 앞에, run 2가 뒤에 있다. 2일차는 monkey2, dmh, monkey5가 같은 방식이다. ⚠️(논문 근거)
- run-01과 run-02가 같은 장면이라는 것을 데이터로 확인하지는 않았다(두 run의 시계열 비교는 하지 않음). 추정 길이가 두 run에서 같고 논문 문구와도 맞는다.

## 6. 세션 간 반복 (F)

| 과제 | 세션 간 반복 피험자 | 비고 |
|---|---|---|
| inscapes | 17 | 세션당 1 run. sub-17은 3세션 |
| rest | 17 | 같음 |
| checker | 17 | 같음 |
| peer | 15 | 7명은 1 run뿐 |
| 서사 영화(dme, dmh, tp, monkey1·2·5) | 1 (sub-17 tp) | 1일차 영화와 2일차 영화가 다름 |

- 판정 F: ⚠️ 한 가지로 정해지지 않는다.
  - §4 통과 조건("세션 간 반복 run이 있어야 함")은 문언상 inscapes(17명)로 충족된다.
  - 그러나 §5 F에서 inscapes는 조작 점검용이고, rest는 하한 점검용이다. 주 자극으로 생각한 서사 영화에는 세션 간 반복이 없다.
  - §4 대안("같은 세션 반복만 있으면 '세션 내 신뢰도'로 이름을 바꾼다")도 그대로 들어맞지 않는다. 영화는 같은 세션 반복만 있고, inscapes는 세션 간 반복만 있기 때문이다.
- 연구책임자가 정할 것(둘 중 하나):
  1. F의 주 분석을 inscapes 세션 간 재검사(N = 17)로 바꾸고, 서사 영화 세션 내 반복은 보조로 둔다. §5 F의 "N이 22명 안팎" 서술은 17명으로 고쳐야 한다. N = 17이면 ICC 0.4 기준의 판단 불가 가능성이 더 커진다.
  2. 서사 영화를 주 자극으로 유지하고, F를 "세션 내 신뢰도"로 이름을 바꾼다(H4를 시험했다고 보고하지 않음). §4 대안에 따라 V13(HCP 7T)으로 옮기는 경로도 있다.
- 세션 간격(중앙값 11일, 2–354일)은 논문 수치이며, 피험자별 간격은 데이터에서 알 수 없다. F의 "개인 특성" 해석에 영향을 준다. ❓

## 7. checker (HRF 추정)

- 22명 모두 checker fMRI(볼륨 + parcel + 움직임)가 있다. 17명은 세션마다 1 run씩 있다. ✅
- 실측 길이: sub-01 ses-01 checker는 98 TR(205.8 s)이다. 논문의 run 길이는 200 s이고, 설계는 "20-second trials following a 20-second rest period across five repetitions"다. ✅(길이) / ⚠️(설계는 논문 근거)
- 이벤트 타이밍 파일은 EEG 폴더의 `*_task-checker_events.tsv`에 있다. raw·preproc 목록 전체에서 `/func/` 아래 events 파일은 0개다. fMRI 시각과 맞추는 방법은 확인하지 않았다. ❓

## 10. 남은 불확실성

1. run-01과 run-02가 같은 장면이라는 것은 논문 문구에 근거한다. 데이터로는 확인하지 않았다. 1명의 두 run의 시각 parcel 시계열 상관으로 확인할 수 있다(파일 1개 추가). ⚠️
2. 과제 코드와 자극의 대응(dme = English 1:02:09–1:12:09, dmh = Hungarian 0:12:12–0:22:12)은 논문과 데이터 배치의 일치에 근거한 추론이다. ⚠️
3. 피험자별 세션 간격을 알 수 없다. ❓
4. checker fMRI의 자극 시각: func events 파일이 없다. EEG events와 fMRI를 맞추는 방법은 확인하지 않았다. ❓
5. run별 TR 수는 두 run만 실측했다. 나머지는 바이트 기반 추정이다.
6. sub-07 ses-02 dmh run-01은 parcel이 없다. 볼륨에서 직접 추출하면 dmh도 17명이 된다.
7. PLAN §2.1의 수정 사항: NATVIEW 과제 행에 dmh, monkey2, monkey5(ses-02 전용)를 추가해야 한다. checkeroff와 checkerout에는 fMRI가 없다. "22명은 이전 대화의 주장"은 이제 ✅(participants.tsv)다. PLAN은 이 문서에서 고치지 않았다.
